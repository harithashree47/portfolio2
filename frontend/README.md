# Haritha Shree G – Portfolio (React + Vite + AOS)

## Run locally
    npm install
    npm run dev

## Build and deploy (Netlify)
    npm run build        # outputs /dist
Netlify settings: build command `npm run build`, publish directory `dist`.

## Edit your content
- Projects, skills, tech strip, typed roles: `src/data.js`
- Sections and text: `src/App.jsx`
- All styling: `src/styles.css`
- Hero code card text: the `CODE` string at the top of `src/App.jsx`.
